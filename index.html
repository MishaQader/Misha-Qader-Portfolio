Aurelia Grand Hotel

2026 • Flutter Application
Development Project

Aurelia Grand Hotel is a Flutter-based hotel management and customer service application designed to provide users with a convenient digital platform for exploring hotel facilities and services.

The application brings different hotel services together in a single interface, allowing customers to explore restaurants, decorations, health club facilities, hotel information and official conference services.

One of the important parts of the application is the Official Conferences module, which allows users to explore available conference options and submit booking information. Firebase and Cloud Firestore are used to manage conference-related booking data.

While developing this project, I focused on creating a clean, user-friendly interface and understanding how different hotel services can be organized into separate modules while still working together as one application.

Key Features:
  • Customer Dashboard
  • Restaurant Services
  • Decorations Services
  • Health Club
  • Our Story / Hotel Information
  • Official Conferences
  • Conference Booking
  • Booking Data Management through Firebase
  • Cloud Firestore Integration

My Learning: This project has strengthened my understanding of Flutter UI development, application navigation, modular design, Firebase integration, Cloud Firestore and converting service requirements into a practical mobile application.

Technologies: Flutter • Dart • Firebase • Cloud Firestore
